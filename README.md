# Order Clicker (Android)

1. Open this folder in Android Studio (Koala or newer), let Gradle sync.
2. Run on your phone (USB debugging) or Build > Build APK(s).
3. In the app, log in to Telegram Web (use "Log in by phone number"; QR needs a second device).
4. Open the bot chat so the orders are visible.
5. Set min/max (default 6000-10000), keep "Dry run" ticked, press START.
   When the log shows the right orders, untick Dry run and START again.
6. Keep the app open and the screen on.
